# Drop Simulator Frontend

This project has been modernized to use **Vite + React**.

## Prerequisites

You need to have **Node.js** installed on your computer.
Download it here: [https://nodejs.org/](https://nodejs.org/) (Project recommends the LTS version).

## Installation

1. Open a terminal in this folder (`simuladorhistory`).
2. Run the following command to install dependencies:
   ```bash
   npm install
   ```

## Running the Project

To start the development server:

```bash
npm run dev
```

Then open the URL shown in the terminal (usually `http://localhost:5173`).

## Building for Production

To create a production build:

```bash
npm run build
```

The files will be generated in the `dist` folder.
